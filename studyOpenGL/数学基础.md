# <center>变换
<font size=6>&emsp;&emsp;基础变换矩阵是表示纯平移、纯旋转和纯缩放的变换矩阵。矩阵分为四个部分：

    ——       ——
    | M M M t |
    | M M M t |
    | M M M t |
    | 0 0 0 1 |
    ——       ——

<font size=6>其中M(3 * 3)代表旋转和缩放，t(3*1)代表平移，[0 0 0 1]就是普通的0 1。
&emsp;&emsp;对于点向量，需要把w分量设为1；方向向量，则w分量为0

##### &emsp;&emsp;1.平移矩阵
&emsp;&emsp;对于**点向量**：
<font size=5>

    ——       ——  ——  ——  ——    ——
    | 1 0 0 tx | | x  |  | x+tx |
    | 0 1 0 ty | | y  |= | y+ty |
    | 0 0 1 tz | | z  |  | z+tz |
    | 0 0 0  1 | | 1  |  |  1   |
    ——       ——  ——  ——  ——    ——

通过该方法使得(x, y, z)实现了平移(tx, ty, tz)个单位的效果。
&emsp;&emsp;而对于**方向向量**：
<font size=5>

    ——       ——  ——  ——  —— ——
    | 1 0 0 tx | | x  |  | x |
    | 0 1 0 ty | | y  |= | y |
    | 0 0 1 tz | | z  |  | z |
    | 0 0 0  1 | | 0  |  | 0 |
    ——       ——  ——  ——  —— ——

平移矩阵的逆矩阵就是**其他全不变，tx，ty，tz取反**。且平移矩阵不是逆矩阵。

##### &emsp;&emsp;2.缩放矩阵
&emsp;&emsp;对于**点向量**：
<font size=5>

    ——          ——  ——  ——   ——      ——
    | kx 0  0  0 |  | x  |   | (kx)*x |
    | 0  ky 0  0 |  | y  | = | (ky)*y |
    | 0  0  kz 0 |  | z  |   | (kz)*z |
    | 0  0  0  1 |  | 1  |   |    1   |
    ——          ——  ——  ——   ——      ——

通过该方法使得(x, y, z)实现了平移(tx, ty, tz)个单位的效果。
&emsp;&emsp;而对于**方向向量**：
<font size=5>

    ——          ——  ——  ——   ——      ——
    | kx 0  0  0 |  | x  |   | (kx)*x |
    | 0  ky 0  0 |  | y  | = | (ky)*y |
    | 0  0  kz 0 |  | z  |   | (kz)*z |
    | 0  0  0  1 |  | 0  |   |    1   |
    ——          ——  ——  ——   ——      ——
如果kx=ky=kz，则称为统一缩放(uniform scale)，否则称为非统一缩放(nonuniform scale)。
&emsp;&emsp;缩放矩阵的逆矩阵就是**其他全不变，kx，ky，kz取倒数**。

##### &emsp;&emsp;3.旋转矩阵
&emsp;&emsp;绕x轴旋转θ度：
<font size=5>

           ——                ——
           | 1   0     0    0 |
           | 0 cosθ -sinθ   0 |
    Rx(θ)= | 0 sinθ  cosθ   0 |
           | 0  0     0     1 |
           ——                ——

&emsp;&emsp;绕y轴旋转θ度：
<font size=5>

           ——                ——
           | 1   0     0    0 |
           | 0 cosθ -sinθ   0 |
    Rx(θ)= | 0 sinθ  cosθ   0 |
           | 0  0     0     1 |
           ——                ——

&emsp;&emsp;绕z轴旋转θ度：
<font size=5>

           ——                ——
           | 1   0     0    0 |
           | 0 cosθ -sinθ   0 |
    Rx(θ)= | 0 sinθ  cosθ   0 |
           | 0  0     0     1 |
           ——                ——

通过该方法使得(x, y, z)实现了平移(tx, ty, tz)个单位的效果。
&emsp;&emsp;而对于**方向向量**：
<font size=5>

    ——          ——  ——  ——   ——      ——
    | kx 0  0  0 |  | x  |   | (kx)*x |
    | 0  ky 0  0 |  | y  | = | (ky)*y |
    | 0  0  kz 0 |  | z  |   | (kz)*z |
    | 0  0  0  1 |  | 0  |   |    1   |
    ——          ——  ——  ——   ——      ——
如果kx=ky=kz，则称为统一缩放(uniform scale)，否则称为非统一缩放(nonuniform scale)。
&emsp;&emsp;缩放矩阵的逆矩阵就是**其他全不变，kx，ky，kz取倒数**。
